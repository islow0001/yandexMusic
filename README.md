# Yandex Media for Home Assistant

Custom media source for playing Yandex Music in Home Assistant.

## Installation

### Manual
1. Copy `yandex_media` folder to `custom_components/`
2. Add `yandex_media:` to `configuration.yaml`
3. Restart HA

### HACS
1. Add this repository as Custom Repository
2. Install via HACS

## Usage
1. Go to **Media → Browse Media**
2. Select **Yandex Media**
3. Choose a track and play

Add to `configuration.yaml`:
